This folder is a Hostinger upload snapshot, not the live source.

The root of the repo is what deploys via GitHub Pages (see CNAME).
Always edit files in the repo root first, then re-copy them here
before uploading to Hostinger. Do not edit files inside this folder
directly — changes made only here will not be reflected on the
GitHub Pages site and will be overwritten next time this folder is
resynced from root.
